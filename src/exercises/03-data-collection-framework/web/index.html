Deciding what an Indian language model should read

There is not enough Indian-language text on the internet to train a frontier model on it alone — perhaps 250–500 billion words across all 22 scheduled languages, against 15 trillion for English. So the interesting question isn't which datasets are good. It's what you train on instead, what that costs, and how you'd know if you were wrong.
