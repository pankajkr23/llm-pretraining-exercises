What would a 40B India-first model actually train on?

We catalogued 145 candidate datasets, graded each against five checks, measured tokenizer cost across 22 languages and 5 tokenizers, and built a contamination gate over 411,442 fingerprints. Then we tried to assemble a 15-trillion-token corpus from what survived. Four datasets clear every bar. The blocker is almost never quality.
