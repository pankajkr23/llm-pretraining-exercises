# Re-run set 2026-10-24

**Why.** Before review, every 07 result the page and README rely on was run again by its tracked
producer to add what the historical files lack: a `config_fingerprint` for the two codec
measurements, a repo-relative run path, and provenance for the figures that tracked code can
reproduce. The historical files in [`results/`](../../) are unchanged and remain what the page renders.

**How.** From commit `fd18c2e190b8` **with uncommitted edits in the tree** (the producers being
changed, and other exercises' packages). The `code_digest` in the three bundles measured today,
`sha256:814871d074d16b73…`, identifies the code that actually ran, and the commit alone does not.
CPU only. Nothing measured today is a timing, so sharing the machine with other jobs cannot have
moved a number here; the `seconds` in `rerun.json` are the 2026-09-08 run's own.
