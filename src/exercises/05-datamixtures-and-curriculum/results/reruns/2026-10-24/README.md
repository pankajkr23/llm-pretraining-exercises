# Re-run, 2026-10-24

Generated by `uv run python -m mixture` from the bundles in this directory and the published runs in [`results/`](../../). **The published files are not modified**: a published experiment is never rewritten, and a re-run is added beside it.

## Why it was run

The published runs read the code lane — this repository's own Python — from the working tree. It grew from 87 files and 352,415 training tokens to 378 files and 1,970,257 (5.6x), so the corpus they measured could no longer be rebuilt from anything, and a re-run on the live tree would have been a different experiment under the same name. **These are the first runs on a frozen lane**, read from git at commit `fd18c2e` and never from disk. Arms, seeds, steps, model shapes and thresholds are unchanged.

## How

Run from commit `fd18c2e` **with uncommitted edits in the tree** — the provenance module and the frozen lane itself were not yet committed — so the commit alone does not reproduce them; each bundle's `code_digest` identifies exactly the code that ran. 2 distinct code digest(s) across these files: the producers were edited between runs (where they write, nothing they compute). Device `mps:apple-silicon`.

`step0.live-lane.json` is Step 0 run on the **live** code lane, before it was frozen — the run that first showed the divergence. It came from `experiment.run` through a wrapper that was never committed: the wrapper skipped the per-seed run records and, instead of refusing on a mid-run input change, recorded whether one happened (`preview_inputs_moved_during_run: false`). Its code lane was the working tree, which no commit holds, so it carries no `code_lane` field and cannot be rebuilt. It is kept as the first sighting, not as evidence on its own.

## Conclusions

- **Holds:** H1, H2. No effect size moved by more than 0.14 percentage points.
- **Diverges:** H3 (refuted → supported). H3's second clause is decided by whether another lane gains more than 1%, and the deciding gain sits near that bar in both runs — 1.12% published, 0.93% now, inside a 2.41% seed spread. Only the code lane's text changed, so a verdict that moves with it was a verdict about that text rather than about the mixture. The published conclusion stays as drawn; the documents carry a dated note beside it.
- **The divergence predates the freeze.** The live-lane run reached the same H3 verdict before the lane was pinned, so freezing did not cause it.
- **Diverges:** E4 (refuted → qualified). On the second STEM stand-in the gain is 1.51%, past the 1% bar, but inside its own 2.57% seed spread, so the clause fires on the point estimate and settles nothing.
- **Diverges:** E3 (assumption survives → order moves, inside noise). 1 pair(s) change places (C/D), but none is separated by more than its own seed spread at both ends, so the movement ranks nothing.
- **Not comparable:** throughput (the machine was shared with other jobs), and the repetition curve's epoch counts (a larger corpus makes the same fractions fewer passes).
