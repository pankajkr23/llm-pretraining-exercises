06 · Training data execution

What did it read on day forty?

A model is trained for fifty days. Something looks wrong, and you want to know which text it read on day forty. You open the folder and find thirty gigabytes of files and no way to answer. The obvious fix is to work it out again from the code that chose the order — which produces a confident answer about a run that did not happen as soon as one line of that code changes. The other fix is to write it down as it happens and read it back. This page is three arguments for the second one, and each of them names what it cannot prove.
