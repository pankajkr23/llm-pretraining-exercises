11 · Optimizers and learning-rate schedules

An optimiser's opening is not its steady state

Adam is written as one formula, applied the same way at every step. A run does not behave the same way at every step. Its opening is shaped by averages that start empty, weights that start small and a learning rate that starts low — and the opening lasts far longer than its name suggests. Every effect here is measured, and set against the difference two identical runs show for no reason at all.
