13 · Reversible training

Run the network backwards instead of remembering it

To learn from a guess, a network has to look again at every step it took to make it — so ordinary training keeps all of those steps in memory. A reversible network keeps only the top of the stack and rebuilds the rest, by running its own update rule in reverse, at the cost of running each layer again. The memory falls, the batch that fits grows, and a rule for doing it was refused before it could be used, because the gradients it rebuilt were no longer the true ones.
